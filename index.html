Guía de Entrenamiento con CVAT & Machine Learning

Detección de Patentes Chilenas y Antifraude (Adulteradas / Clonadas)
Paso 1

Recolección del Dataset Chileno

Para entrenar una IA robusta capaz de trabajar en la calle o con cámaras de celular, necesitas recopilar entre 300 y 1.000 imágenes:

  • Patentes reales auténticas: Vehículos en tránsito, distintas horas (sol directo, sombra, noche con focos), ángulos (frontal, lateral 30°).
  • Patentes adulteradas / trucadas: Muestras de prueba con cinta aislante negra modificando letras (ej: convertir F en E, P en R, 1 en 4).
  • Patentes clonadas: Placas impresas en papel, cartón o acrílico sin troquelado ni relieve metálico.
Paso 2

Anotación en CVAT (Computer Vision Annotation Tool)

Entra a cvat.ai ↗ (gratuito) o corre CVAT con Docker localmente:

  1. Crea una nueva Task con el nombre Chilean_Plates_AntiTamper.
  2. Define las siguientes Labels (Etiquetas) de tipo Rectangle:
    0: plate_authentic 1: plate_tampered_tape 2: plate_cloned_replica 3: plate_2026_5L1D 4: plate_moto_2026_4L1D 5: plate_moto_3L2D
  3. Sube tus imágenes y dibuja el rectángulo ajustado al borde de cada placa patente.
Paso 3

Exportar Dataset en Formato YOLOv8

En el menú de tu tarea en CVAT, haz clic en Export Task Dataset y selecciona el formato YOLO 1.1 (YOLOv8 Detection).

CVAT generará un archivo .zip con las imágenes y archivos .txt donde cada línea contiene: <class_id> <x_center> <y_center> <width> <height> (normalizados de 0 a 1).

Paso 4

Entrenamiento del Modelo con YOLOv8 en Python

Copia y ejecuta este script en Google Colab con GPU gratuita:

# 1. Instalar Ultralytics
!pip install -q ultralytics

from ultralytics import YOLO

# 2. Cargar modelo base ultraliviano para visión en tiempo real (60+ FPS)
model = YOLO('yolov8n.pt')

# 3. Entrenar con el dataset exportado de CVAT
model.train(
    data='dataset.yaml', 
    epochs=60, 
    imgsz=640, 
    batch=16,
    plots=True
)

# 4. Validar y exportar a formato web ONNX o TensorFlow.js
model.val()
model.export(format='onnx')
